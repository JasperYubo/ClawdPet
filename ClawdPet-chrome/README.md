# Clawd 桌宠 · Chrome 扩展版

Clawd 住进你的网页里，Chromebook 和任何电脑上的 Chrome 都能用。默认是两只，会一起玩。

## 安装

1. 在仓库首页点 **Code → Download ZIP**，解压，找到里面的 `ClawdPet-chrome` 文件夹，放到一个以后不会删的地方（删了扩展就没了）。
   - Chromebook：在「文件」应用里双击 zip，把 `ClawdPet-chrome` 文件夹复制到「下载内容」或「我的文件」。
2. Chrome 地址栏输入 `chrome://extensions` 回车。
3. 打开右上角的「开发者模式」。
4. 点「加载已解压的扩展程序」，选中 `ClawdPet-chrome` 文件夹。
5. 点工具栏的拼图图标，把「Clawd 桌宠」固定到工具栏。已经打开的网页里 Clawd 会直接掉下来。

学校 / 公司管理的 Chromebook 可能不让开「开发者模式」，那就装不了。

### 更新

别再点一次「加载已解压的扩展程序」，那样会装成两份。把新的文件覆盖到原来的文件夹，再在 `chrome://extensions` 里点 Clawd 卡片上的刷新按钮。

## 两只 Clawd

第二只头顶长着一根小芽。它们会打招呼、贴贴、你追我跑、互相传球、一起跳舞、挨着睡觉；你喂一只，另一只眼巴巴看着；你摸一只，另一只会吃醋。只想要一只：菜单或工具栏里关掉「两只 Clawd（会一起玩）」。

## 它自己会做的事

- 走路、小跑、坐下、趴着、东张西望、托腮想事情、挠头、伸懒腰、蹦跶、转圈、打滚、做操、打喷嚏、跳舞
- 跳到网页的标题、图片、按钮、卡片上走来走去，坐在边上晃腿；网页滚动时跟着元素一起动
- 走到屏幕边上，躲在外面只露半个身子偷看
- 你打字时坐下来陪你；网页上有视频在放，它会跑过去坐着看
- 打盹、冒鼻涕泡、做梦（梦到饼干、苹果、球……）；3 分钟不碰电脑会睡觉，你一动就醒

## 怎么跟它玩

- 鼠标在它身上停一下，头顶冒出快捷按钮：喂一口 / 扔个球 / 睡觉 / 做个梦 / 更多（触屏：点它一下）
- 单击蹲下再弹起来，双击跳舞，连续戳 6 下被戳晕
- 在它身上来回蹭：摸摸；蹭得快一点：挠痒痒
- 按住把它拎起来，像钟摆一样晃，甩出去有重力和弹跳，可以扔到标题、图片上
- 把网页上的文字、链接拖到它身上：嚼一嚼，告诉你有多少字
- 做梦时点它头上的云朵泡泡，钻进梦里玩一关横版跑跳小游戏（← → / A D 走，空格跳，Esc 醒来）

## 菜单

右键点它：陪它玩（喂零食 / 扔个球 / 跳舞）、睡一会儿、说句话、番茄钟、提醒我、跟着鼠标走、偶尔自言自语、久坐提醒、大小、在这个网站隐藏、关掉。工具栏图标里也有这些。番茄钟和提醒到点会弹系统通知，网页关掉了也照样提醒。

## 限制

Chrome 扩展只能在网页里画东西，所以 Clawd 不会出现在 ChromeOS 桌面、设置页、`chrome://` 页面和 Chrome 应用商店里。
